# Spec Delta

## Purpose

定义主题、字号、密度、动效和中英文切换，使用户可以按环境调整界面，同时保持可访问性和一致的日期、数字格式。

## ADDED Requirements

### Requirement: 主题切换

本要求为强制要求（MUST）。

应用必须支持浅色、深色和跟随系统三种主题。切换后无需重启即可生效，并持久化到本地设置；跟随系统时必须在系统主题变化后更新界面。

#### Scenario: 手动切换深色

- **WHEN** 用户选择深色主题
- **THEN** 所有主要界面立即使用深色令牌
- **AND** 重启后仍为深色

#### Scenario: 跟随系统变化

- **WHEN** 主题为跟随系统且操作系统切换到深色
- **THEN** 应用界面同步切换到深色
- **AND** 不要求用户重启

### Requirement: 字号与密度

本要求为强制要求（MUST）。

用户必须能够调整界面字号和列表密度。调整后布局不得溢出或遮挡主要操作，会话列表和设置表格必须保持可用。

#### Scenario: 增大字号

- **WHEN** 用户把字号调大
- **THEN** 正文和控件同步放大
- **AND** 主要按钮和输入框仍可完整操作

### Requirement: 减少动效

本要求为强制要求（MUST）。

应用必须尊重系统的减少动效偏好，并提供手动开关。开启后不得播放非必要动画，流式文本和状态更新仍必须可见。

#### Scenario: 系统减少动效

- **WHEN** 操作系统开启减少动效
- **THEN** 应用默认关闭过渡动画
- **AND** 状态变化仍通过文字或静态标记呈现

### Requirement: 中英文切换

本要求为强制要求（MUST）。

应用必须支持简体中文和 English，切换后无需重启即可更新界面文案。日期、数字和代码字体必须跟随语言正确显示；缺失翻译不得显示原始键名。

#### Scenario: 切换到 English

- **WHEN** 用户选择 English
- **THEN** 导航、按钮、空状态和错误提示切换为英文
- **AND** 当前页面状态和未保存输入保持不变

#### Scenario: 缺失翻译

- **WHEN** 某个界面文案没有目标语言翻译
- **THEN** 应用回退到另一种已配置语言
- **AND** 不显示类似 `settings.title` 的原始键名

### Requirement: 外观设置持久化

本要求为强制要求（MUST）。

主题、语言、字号、密度和减少动效必须持久化并在应用启动时尽早应用，避免先显示错误主题再闪烁切换。

#### Scenario: 启动时恢复外观

- **WHEN** 用户上次使用深色主题和英文
- **THEN** 启动首屏即使用深色和英文
- **AND** 不出现明显的浅色闪烁
