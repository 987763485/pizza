# Spec Delta

## Purpose

定义用户如何创建、配置和维护可被会话使用的智能体，确保每个智能体都有明确的身份、运行时绑定和可验证的执行配置。

## ADDED Requirements

### Requirement: 智能体列表

本要求为强制要求（MUST）。

设置中的智能体列表必须展示头像、名称、描述、绑定运行时、在线状态和最近使用时间，并支持按名称搜索。列表在 20 个智能体下必须保持可滚动且不丢失操作入口。

#### Scenario: 搜索智能体

- **WHEN** 用户在智能体搜索框输入名称片段
- **THEN** 列表只显示名称或描述匹配的智能体
- **AND** 清空搜索后恢复完整列表

### Requirement: 创建与必填校验

本要求为强制要求（MUST）。

用户必须能够创建智能体，至少填写唯一名称、非空初始 Prompt 和可用运行时。校验失败时必须在对应字段旁说明原因，不得保存部分无效记录。

#### Scenario: 名称重复

- **WHEN** 用户输入已存在的智能体名称并保存
- **THEN** 名称字段显示重复错误
- **AND** 智能体不被保存

#### Scenario: 运行时不可用

- **WHEN** 用户选择的运行时已离线或未注册
- **THEN** 表单阻止保存并说明运行时不可用
- **AND** 用户可以改选其他在线运行时

### Requirement: 智能体身份与头像

本要求为强制要求（MUST）。

每个智能体必须有稳定的身份标识和默认生成的头像。用户必须能够上传头像或使用随机生成；上传文件必须是图片、裁剪为方形且不超过 2 MB，超出限制时给出明确错误。

#### Scenario: 默认头像稳定

- **WHEN** 用户创建智能体后多次重启应用
- **THEN** 该智能体的默认头像保持一致
- **AND** 头像是根据智能体标识确定生成的

#### Scenario: 上传超大头像

- **WHEN** 用户选择大于 2 MB 的图片作为头像
- **THEN** 应用拒绝上传并显示文件大小限制
- **AND** 原头像保持不变

### Requirement: 智能体配置

本要求为强制要求（MUST）。

智能体必须支持配置描述、运行时绑定、初始 Prompt、思考强度和上下文压缩阈值。上下文压缩阈值必须按 100k token 步长调整，默认值为 100k 或 200k。

#### Scenario: 调整上下文阈值

- **WHEN** 用户在智能体编辑页拖动上下文压缩阈值
- **THEN** 数值按 100k 步长变化
- **AND** 保存后新建会话使用该阈值

#### Scenario: 运行时能力受限

- **WHEN** 绑定的运行时不支持所选思考强度
- **THEN** 表单禁用该选项并解释原因
- **AND** 不允许保存与运行时不兼容的值

### Requirement: 编辑与复制

本要求为强制要求（MUST）。

用户必须能够编辑已有智能体，并将其配置复制为新智能体。复制后的智能体必须有新的标识和唯一名称，不得与原智能体共享可变配置。

#### Scenario: 复制智能体

- **WHEN** 用户对智能体选择「复制」
- **THEN** 应用创建一个带新标识的新记录
- **AND** 修改新记录不影响原智能体

### Requirement: 归档与删除

本要求为强制要求（MUST）。

用户必须能够归档智能体，归档后该智能体不再出现在新建会话的选择器中，但历史会话仍可显示其名称和头像。永久删除前必须二次确认，并列出受影响的会话或团队；删除被引用智能体时必须要求用户确认处理方式。

#### Scenario: 归档智能体

- **WHEN** 用户归档一个已有历史会话的智能体
- **THEN** 新会话选择器不再列出该智能体
- **AND** 历史会话仍然显示该智能体的名称和头像

#### Scenario: 删除被引用智能体

- **WHEN** 用户尝试永久删除一个被活跃会话引用的智能体
- **THEN** 应用展示受影响会话数量并要求二次确认
- **AND** 未确认前不执行删除

### Requirement: 测试智能体

本要求为强制要求（MUST）。

用户必须能够在不写入正式会话的情况下向智能体发送测试消息，并查看运行时、耗时和错误。测试记录不得出现在会话历史或统计的正式运行中。

#### Scenario: 测试成功

- **WHEN** 用户在智能体编辑页发送测试消息
- **THEN** 界面显示流式结果、运行时名称和耗时
- **AND** 会话历史中不新增会话

#### Scenario: 测试失败

- **WHEN** 测试消息因运行时错误失败
- **THEN** 界面显示失败阶段和可操作错误
- **AND** 智能体配置保持不变
