# team-management Specification

## Purpose
定义用户如何创建和维护智能体团队，包括指挥者、成员、成员级覆盖、团队编排 Prompt 与内置模板，并保证团队配置在进入会话前是有效且可解释的。

## Requirements

### Requirement: 团队列表与搜索

本要求为强制要求（MUST）。

设置中的团队列表必须展示团队头像、名称、描述、成员数、指挥者和最近使用时间，并支持按名称或描述搜索。团队列表必须按最近使用优先排序。

#### Scenario: 搜索团队

- **WHEN** 用户在团队搜索框输入名称片段
- **THEN** 列表只显示名称或描述匹配的团队
- **AND** 清空搜索后恢复按最近使用排序的完整列表

### Requirement: 创建与编辑团队

本要求为强制要求（MUST）。

用户必须能够创建和编辑团队，填写唯一名称、描述和头像。保存前必须校验名称唯一性；团队头像支持默认生成、上传和预设。

#### Scenario: 名称重复

- **WHEN** 用户输入已存在的团队名称并保存
- **THEN** 名称字段显示重复错误
- **AND** 团队配置不被保存

#### Scenario: 默认团队头像

- **WHEN** 用户创建一个没有上传头像的团队
- **THEN** 系统生成基于团队成员头像的默认头像
- **AND** 成员变化后该默认头像可以刷新

### Requirement: 指挥者必须是团队成员

本要求为强制要求（MUST）。

团队必须指定一名指挥者，且指挥者必须属于团队成员。更换指挥者必须立即生效；未指定指挥者或指挥者不在成员列表时不得保存。

#### Scenario: 选择非成员作为指挥者

- **WHEN** 用户选择一个不在成员列表中的智能体作为指挥者
- **THEN** 表单阻止保存并说明指挥者必须先是成员
- **AND** 用户可以先添加该智能体为成员

#### Scenario: 更换指挥者

- **WHEN** 用户把指挥者从成员 A 改为成员 B 并保存
- **THEN** 团队记录的指挥者立即更新为 B
- **AND** 后续新建团队会话默认路由给 B

### Requirement: 成员添加与排序

本要求为强制要求（MUST）。

用户必须能够从智能体库添加成员、调整成员顺序和移除成员。重复添加必须被阻止；团队必须至少保留指挥者，移除指挥者前必须先更换指挥者。

#### Scenario: 添加重复成员

- **WHEN** 用户尝试添加一个已在团队中的智能体
- **THEN** 该智能体在候选列表中被禁用或提示已添加
- **AND** 团队成员列表不出现重复项

#### Scenario: 移除最后一名成员

- **WHEN** 用户尝试移除团队唯一成员且该成员是指挥者
- **THEN** 应用阻止移除并提示先更换指挥者
- **AND** 团队成员列表保持不变

### Requirement: 成员级 Prompt 覆盖

本要求为强制要求（MUST）。

团队成员必须支持替换或追加 Prompt 覆盖。覆盖项必须在成员卡片上可见，并可一键恢复继承智能体自身配置。最终生效 Prompt 必须可预览。

#### Scenario: 追加成员 Prompt

- **WHEN** 用户为成员选择「追加」并填写团队专用约束
- **THEN** 该成员在团队中的有效 Prompt 包含智能体原 Prompt 和追加内容
- **AND** 修改智能体自身 Prompt 后仍然继承最新内容

#### Scenario: 恢复继承

- **WHEN** 用户点击成员覆盖的「恢复继承」
- **THEN** 该成员删除团队级覆盖
- **AND** 预览恢复为智能体自身配置

### Requirement: 团队编排 Prompt

本要求为强制要求（MUST）。

团队必须支持独立的编排 Prompt，用于规定指挥者如何分派、质询、处理插话和收敛。编排 Prompt 必须与指挥者自身 Prompt 分离，并提供最终生效内容预览。

#### Scenario: 预览最终编排 Prompt

- **WHEN** 用户编辑团队编排 Prompt
- **THEN** 预览区同时展示指挥者自身 Prompt 和团队编排 Prompt
- **AND** 两者边界清晰可辨认

### Requirement: 团队有效性校验

本要求为强制要求（MUST）。

保存团队前必须校验名称唯一、成员非空、指挥者在成员中、成员不重复，以及团队引用不形成循环。校验失败必须定位到具体字段或成员。

#### Scenario: 成员引用循环

- **WHEN** 团队配置检测到成员引用形成循环
- **THEN** 保存被阻止并指出涉及的成员
- **AND** 用户修正后可以重新保存

### Requirement: 内置头脑风暴模板

本要求为强制要求（MUST）。

系统必须提供内置「头脑风暴队」模板，预填主持人、产品经理、架构师、唱反调者和用户研究员角色，以及对应的团队编排 Prompt。用户必须能够从模板创建可编辑的团队，而不是只能使用固定团队。

#### Scenario: 从模板创建团队

- **WHEN** 用户选择「头脑风暴队」模板
- **THEN** 表单预填五名角色和编排 Prompt
- **AND** 用户可以在保存前修改成员、角色描述和 Prompt

### Requirement: 团队归档与删除

本要求为强制要求（MUST）。

用户必须能够归档和永久删除团队。删除前必须二次确认，并展示受影响的会话和成员关系；归档团队不得出现在新建会话的团队选择器中，但历史会话仍可显示其名称和头像。

#### Scenario: 删除被会话引用的团队

- **WHEN** 用户尝试删除一个仍有历史会话的团队
- **THEN** 应用显示受影响会话数量并要求二次确认
- **AND** 用户取消时不删除任何团队或会话
