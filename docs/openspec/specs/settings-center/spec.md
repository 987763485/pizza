# settings-center Specification

## Purpose
定义 Pizza 设置中心的导航、个人与系统配置、归档会话和关于信息，确保用户可以在图形界面中完成日常配置，且设置在重启后保持有效。

## Requirements

### Requirement: 设置导航

本要求为强制要求（MUST）。

设置中心必须提供分组导航：个人包含个人资料、语言与外观；数据包含记忆管理和已归档会话；团队包含智能体、智能体团队、Skills、MCP、运行时和统计；系统包含系统设置和关于 Pizza。当前页必须高亮，所有入口可达。

#### Scenario: 打开设置

- **WHEN** 用户从侧栏点击设置
- **THEN** 打开独立设置视图并显示品牌与分组导航
- **AND** 当前页具有可见高亮

#### Scenario: 未交付的 P1 页面

- **WHEN** 用户打开尚未完整交付的记忆或统计页面
- **THEN** 页面明确标注规划中或不可用
- **AND** 不展示伪造数据

### Requirement: 个人资料

本要求为强制要求（MUST）。

用户必须能够查看和修改个人显示名称、头像和本地账户说明。头像支持上传和随机生成，上传限制与智能体头像一致；修改后应用内头像立即更新并持久化。

#### Scenario: 修改个人头像

- **WHEN** 用户上传一张不超过 2 MB 的图片
- **THEN** 左下角账户头像和设置页预览同时更新
- **AND** 重启应用后仍显示新头像

### Requirement: 系统默认值

本要求为强制要求（MUST）。

系统设置必须支持默认工作区 `~/Pizza`、默认运行时 Pi、最大并发数、数据目录 `~/.pizza`、日志级别、自动更新开关和匿名统计开关。修改必须说明影响；需要重启的项必须明确标注。

#### Scenario: 修改默认工作区

- **WHEN** 用户设置新的默认工作区并保存
- **THEN** 后续没有指定工作区的新会话使用该目录
- **AND** 已有会话路径保持不变

#### Scenario: 数据目录不可写

- **WHEN** 用户选择一个不可写的数据目录
- **THEN** 设置页显示路径和权限错误
- **AND** 不切换数据目录

### Requirement: 数据目录变更

本要求为强制要求（MUST）。

修改数据目录前必须提示需要重启并确认迁移方式。应用必须在重启后迁移或切换到新目录；迁移失败时保留原目录并给出恢复说明，不得删除原数据。

#### Scenario: 确认迁移

- **WHEN** 用户选择新的数据目录并确认迁移
- **THEN** 应用记录待迁移状态并在重启后执行
- **AND** 失败时继续使用原目录

### Requirement: 已归档会话

本要求为强制要求（MUST）。

设置中的已归档会话必须支持恢复、永久删除和批量清理。永久删除前必须二次确认；恢复后会话回到原工作区并保留消息。

#### Scenario: 批量清理

- **WHEN** 用户选择多个归档会话并确认永久删除
- **THEN** 这些会话及其消息被删除
- **AND** 未选中的归档会话保持不变

### Requirement: 关于 Pizza

本要求为强制要求（MUST）。

关于页必须展示版本、构建号、开源协议、第三方归属和反馈入口。链接必须可打开；版本信息必须与实际安装包一致。

#### Scenario: 查看版本

- **WHEN** 用户打开关于 Pizza
- **THEN** 显示当前安装包的实际版本和构建号
- **AND** 第三方归属信息可展开查看

### Requirement: 设置持久化与校验

本要求为强制要求（MUST）。

所有设置必须持久化到本地数据库或受保护的配置文件，并在重启后生效。保存前必须校验类型和范围；无效值不得覆盖已有有效设置。

#### Scenario: 重启后保留设置

- **WHEN** 用户修改主题、语言或默认运行时并重启应用
- **THEN** 设置保持为新值
- **AND** 相关界面使用新值

#### Scenario: 无效并发数

- **WHEN** 用户输入超出允许范围的最大并发数
- **THEN** 表单显示范围错误
- **AND** 原设置保持不变
