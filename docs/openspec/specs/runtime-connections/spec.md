# runtime-connections Specification

## Purpose
定义 Pizza 如何注册、测试、探测和维护本机运行时连接，使用户能够接入 ACP 或 CLI 运行时，并在连接失效时看到真实状态和可操作的恢复路径。

## Requirements

### Requirement: 运行时注册字段

本要求为强制要求（MUST）。

用户必须能够创建运行时记录，至少包含名称、适配器、传输方式、启动命令或连接地址、可选参数、超时和自动重连设置。缺少必填字段时不得保存。

#### Scenario: 创建 stdio 运行时

- **WHEN** 用户选择内置适配器并填写可执行命令、参数和超时
- **THEN** 应用保存一条待测试的运行时记录
- **AND** 该记录在测试通过前不得被智能体绑定

#### Scenario: 缺少必填字段

- **WHEN** 用户未填写名称或启动命令就尝试保存
- **THEN** 应用定位到缺失字段并说明原因
- **AND** 不创建运行时记录

### Requirement: 适配器预设与协议标识

本要求为强制要求（MUST）。

运行时选择器必须提供 Claude Code、Codex、Pi、Oh My Pi、DeepSeek Harness、Hermes 和通用 ACP 的默认模板。每个运行时必须以用户可见的方式标注实际接入协议为「ACP」或「CLI 兼容」，不得把 CLI 适配描述为原生 ACP。

#### Scenario: 选择内置适配器

- **WHEN** 用户选择 Hermes 适配器
- **THEN** 表单预填该适配器的默认命令或地址
- **AND** 界面显示其协议标识为「ACP」

#### Scenario: 选择 CLI 适配器

- **WHEN** 用户选择 Claude Code 适配器
- **THEN** 界面显示其协议标识为「CLI 兼容」
- **AND** 用户仍可修改命令和参数

### Requirement: 分步连接测试

本要求为强制要求（MUST）。

连接测试必须按顺序展示启动进程或连接、握手、创建临时会话、发送测试消息和清理临时资源的结果。成功时必须展示协议版本、检测到的能力和往返延迟；失败时必须展示失败步骤、退出码和截断后的错误输出。

#### Scenario: 连接测试成功

- **WHEN** 用户对一条有效的运行时配置点击「测试连接」
- **THEN** 界面逐步显示五个测试阶段的结果
- **AND** 成功后展示协议版本、能力和往返延迟

#### Scenario: 连接测试失败

- **WHEN** 运行时可执行文件不存在或握手失败
- **THEN** 界面标记具体失败阶段
- **AND** 显示可诊断的错误信息，不显示笼统的「连接失败」

### Requirement: 测试通过后注册

本要求为强制要求（MUST）。

运行时只有在连接测试成功后才能注册为可用状态。未通过测试的记录可以保留为草稿，但不得出现在智能体的可选运行时中。

#### Scenario: 测试失败不注册

- **WHEN** 运行时连接测试在握手阶段失败
- **THEN** 记录保持草稿或失败状态
- **AND** 创建智能体时无法选择该运行时

### Requirement: 能力探测与配置门控

本要求为强制要求（MUST）。

注册成功后，系统必须保存运行时能力，包括可用模型、是否支持运行中追加输入、MCP、Skill 和思考强度。智能体界面必须禁用运行时不支持的能力并解释原因，不得静默忽略配置。

#### Scenario: 运行时不支持思考强度

- **WHEN** 探测结果显示运行时不支持思考强度
- **THEN** 该配置项在智能体表单中禁用
- **AND** 界面说明「当前运行时不支持此能力」

### Requirement: 健康状态与重连

本要求为强制要求（MUST）。

系统必须展示运行时的在线、离线、测试中和错误状态。已注册运行时断线后应标记为离线，并按用户配置尝试重连；重连成功前不得调度新的运行。

#### Scenario: 运行时断线

- **WHEN** 已注册运行时在空闲时失去连接
- **THEN** 运行时列表在五秒内显示离线状态
- **AND** 使用该运行时的智能体不能再接受新的运行

#### Scenario: 重连成功

- **WHEN** 断线的运行时重新可用且用户触发或自动重连成功
- **THEN** 状态恢复为在线
- **AND** 新建运行可以继续调度

### Requirement: 敏感配置保护

本要求为强制要求（MUST）。

运行时环境变量和连接凭据必须以掩码显示并存储在受保护的本地存储中。日志和错误提示不得输出完整密钥、令牌或环境变量值。

#### Scenario: 查看环境变量

- **WHEN** 运行时保存了包含令牌的环境变量
- **THEN** 编辑界面只显示掩码值
- **AND** 导出的日志不包含该令牌的原文
