## 1. 设计方向

### 1.1 关键词

**克制、精确、安静、像一张共享的餐桌。**

Pizza 不是企业仪表盘，也不是霓虹 AI 产品。它应该像一个排版良好的工作笔记本：信息密度高，但呼吸感足够；颜色少而有记忆点；智能体有鲜明的身份，但不喧宾夺主。

### 1.2 品牌隐喻

- **披萨切片**只出现在 Logo、应用图标与空状态插画中，不做拟物化的食物界面。
- 应用图标：白色圆角底 + 一整块披萨缺一片；圆形饼身、右上角缺口、番茄红饼边与辣肠点。缺口表达「切开、分一份、再拼回来」。32px 下仍保持可辨认，界面内品牌标记与图标使用同一路径。
- 主操作用近黑；背景与侧栏使用冷中性灰；番茄红只保留为品牌点缀；在线状态使用亮绿。
- 文案使用「切开」「分一份」「拼回来」等轻量隐喻，但不超过产品名本身，避免油腻。

### 1.3 视觉参考

- 结构参考同类工作台：左侧导航 + 中间内容 + 右侧属性/产出物栏。
- 气质参考编辑部工具：衬线标题、细边框、低饱和、克制的阴影。
- 交互参考聊天工具：消息流、mention chip、流式光标、输入框快捷键。

## 3. 应用框架

### 3.1 窗口

- 桌面端窗口：最小 1180 × 720；默认 1440 × 900。
- 顶部 44px 为可拖拽区；左侧依次为 macOS 交通灯、「折叠左侧栏」「搜索」；中间显示当前会话标题；右侧为主题按钮。
- 搜索紧邻折叠按钮；折叠后左侧栏收为 64px 图标栏。
- 内容区高度 = 窗口高度 − 44px。

### 3.2 三栏

| 区域 | 展开 | 折叠 | 行为 |
| --- | --- | --- | --- |
| 左侧栏 | 264px | 64px | 标题栏按钮折叠；折叠后仅显示图标与新建按钮，设置/帮助/账户固定在底部；悬停显示 tooltip |
| 主区 | 自适应，最小 560px | — | 独立滚动；输入框吸底 |
| 右侧栏 | 320px | 0 | 可手动开关；< 1100px 默认关闭 |

- 栏间用 1px `--line` 分隔，不使用卡片包裹整个主区。
- 主区内容最大宽度 780px，居中；宽屏不无限拉伸。

### 3.3 左侧栏结构

```
[品牌 Pizza]
[＋ 新建对话]                    (主按钮，全宽)

置顶
  [ ] qoder
      制作适配任何 agent 的 Open...
工作区                          [+]
  [▸] Pizza 项目                (当前，高亮)
      移动端要不要做
      接入 Claude Code 运行时
  [ ] report_test
      暂无任务 :)
  [ ] qodercn
      AI时代漏洞扫描系统分析

[底部] 设置 · 帮助 · 头像
```

- 工作区行：文件夹图标、名称、`⋯` 菜单（置顶/编辑/归档工作区）、`+`（在…中新建任务）。
- 置顶工作区进入顶部「置顶」分组；会话打开时只高亮会话行，工作区行不再叠加背景；无会话打开时高亮当前工作区。
- 工作区列表可滚动；折叠侧边栏时隐藏。
- 底部头像打开账户菜单；`?` 打开帮助菜单。

- 每条会话：模式图标（单人/多人）、标题、右侧状态点（运行中/等待你/失败）。
- 悬停显示「⋯」，与右键打开同一会话菜单：重命名、分叉会话、导出会话、归档、永久删除。
- 分叉会话复制当前会话到分叉点，新会话标题追加「（分叉）」，头部显示「分叉」标记。
- 当前会话使用 `--surface-3` 背景 + 左侧 2px 品牌色指示条。
- 设置打开后隐藏应用侧栏，左侧为「Pizza 品牌 + 设置导航 + 底部返回聊天/主题」，右侧为设置内容。

## 5. 页面规格

### P01 首页 / 新建对话

**目标**：让用户在 10 秒内开始一次有价值的工作。

**布局**（垂直居中，最大宽 760px）：

1. 品牌切片 + 标题：`今天想切成哪一块？`
2. 副标题：`选一个智能体，或拉一支团队，从一句话开始。`
3. **启动卡**（大输入框）：
   - 顶部：**参与者下拉**（头像 + 名称 + 下拉箭头）；下拉分组展示「智能体」与「智能体团队」，当前项带勾选。选择智能体即进入单智能体模式，选择团队即进入团队模式——**不再提供独立的分段模式切换**。
   - 中部：多行输入，占位符 `描述你要解决的问题，输入 @ 可以指定智能体…`。
   - 底部：`+`、`@`、`/`、当前工作区（点击打开系统文件夹选择器）、发送按钮。
4. 快捷指令：4 张卡片（如「接入一个运行时」「创建一个头脑风暴队」「让团队评审这段代码」「总结这个仓库」）。
5. 最近会话：最多 3 条，横向卡片。

**交互**：

- 参与者下拉默认选中最近使用的智能体或团队；下拉中的选中项带勾选，列表较长时可搜索。
- 选择参与者后，输入框上方的路由提示与发送目标同步更新；不出现额外的模式切换控件。
- 输入 `@` 打开提及选择器（P15）；在首页只允许选择当前模式内的对象。
- 点击示例卡片：填充输入框，不直接发送。
- 发送后创建会话并进入 P02/P03；首条消息立即显示，运行状态可见。

**空态**：

- 没有智能体：启动卡下方显示「还没有智能体，先接入运行时并创建一个」+ 两个按钮。
- 没有团队：团队模式下的选择器显示「创建你的第一支团队」。

### P02 单智能体对话

**布局**：

- 会话头部（64px）：头像 + 名称 + 描述 + 运行时状态点 + 模式标签「智能体模式」；右侧：搜索、停止、右侧栏开关。
- 消息流：用户右对齐气泡；智能体左对齐，带角色细线与头部信息；工具调用折叠行；状态与时间。
- 输入框：吸底，路由提示 `发送给 @Builder`。
- 右侧栏（默认开）：
  - 「产出物」标题 + 计数；
  - 文件列表（图标、名称、来源智能体、时间）；
  - 「在 VS Code 中打开」按钮；
  - 页签：产出物 / 变更 / Git / 审计（后三者标注 P1）。

**关键交互**：

- 智能体回复时：头部状态「正在工作」，消息末尾显示流式光标；输入框右侧变为「停止」。
- 用户发送：若正在运行且为排队模式，消息显示「已排队」；若为插话模式，显示「已插话」。
- 工具调用：默认一行，失败时自动展开并显示错误；点击展开参数与输出。
- 消息操作：悬停显示复制、引用、重试。

**状态**：

- `running`：状态点脉冲 + 停止按钮。
- `waiting_user`：消息流底部出现「@你 需要你拍板」卡片 + 输入框高亮。
- `failed`：消息内红色错误条 + 重试；保留已输出内容。
- `cancelled`：灰色标记「已停止」。

### P03 团队对话（核心页面）

**布局**：

- 头部：团队头像（成员拼贴）+ 团队名 + `团队模式` 标签 + 指挥者标识 + 成员头像堆叠（展示全部成员，不显示 +N）。
- 消息流：在关键节点插入系统回合分隔线：
  - `第 1 轮 · 指挥者 @产品经理、@架构师、@研究员 并行发散`
  - `第 2 轮 · 交叉辩论`
  - `等待 @你 回复`
- 每条智能体消息：角色色细线、头像、名称、角色标签（`指挥者` / `成员`）、@ chip。
- 右侧栏上半部为「本回合」状态列表：每个成员的头像、状态（排队/工作中/已完成/等待你）、耗时；下半部为产出物。
- 输入框路由提示：`发送给 @指挥者（未指定时）`；输入 @ 可指定成员。

**预置演示数据（原型）**：

- 用户：「我们要不要给 Pizza 加一个移动端？请评估。」
- 指挥者拆解，@产品经理、@架构师、@用户研究员 并行。
- 三人回复；指挥者交叉 @ 进入辩论。
- 用户插话：「先不考虑成本，重点看体验。」（标记为插话）
- 研究员 @我：「目标用户是个人还是团队？」
- 底部显示等待卡片。
- 右上「产出物」有最终 Markdown 预览按钮（可打开）。

**交互**：

- 点击成员头像：打开成员卡片（角色、运行时、当前配置摘要）。
- 点击「@」chip：滚动到该成员最近一条消息。
- 插话模式切换：输入框上方 `排队` / `立即插话`；立即插话在不支持时显示降级提示。
- 停止全部：头部按钮 + 输入框停止；确认后所有运行标记「已停止」。
- 回合结束后：出现「指挥者已汇总」卡片，链接到产出物。

**空态**：

- 团队没有成员：提示「至少添加一个成员」并跳转编辑。
- 所有成员离线：横幅提示运行时离线，消息排队。

### P04 智能体列表

- 顶部：标题 `智能体` + 数量；右侧 `新建智能体`。
- 筛选行：搜索、运行时筛选、状态筛选（全部/在线/离线/已归档）。
- 列表视图（默认）：每行 64px，头像、名称、描述、运行时、状态、最近使用、引用团队数；行尾提供删除；悬停显示「编辑 / 复制 / 归档 / 删除」。
- 空态：插画 + 「接入运行时，创建第一个智能体」。
- 点击行进入 P05。

### P05 智能体编辑

**布局**：全宽页面（非弹窗），左侧 200px 节导航，右侧表单（最大 680px），最右 320px 实时预览。

**节**：

1. **基本资料**
   - 头像（自动生成 / 上传 / 预设 / 随机生成）。
   - 名称（必填，唯一校验）。
   - 描述（一句话，用于指挥者选择）。
   - 对话开场白（最多 3 条：标签 + 内容）[P1]。
2. **运行时**
   - 运行时选择卡（在线状态、协议、能力标签）。
   - 模型（运行时提供时显示；否则「由运行时管理」）。
   - 思考强度：分段控件 `最低 / 低 / 中 / 高 / 最高`。
   - 并发上限（默认 3，范围 1–10）。
   - 自定义环境变量与参数（折叠，标注「可能包含敏感信息」）[P1]。
3. **指令**
   - 指令来源模式：`自带初始 Prompt`（默认）/ `指挥者动态下发`；两种模式均可选。
   - 选择模式二时，Prompt 编辑器变为「单智能体兜底 Prompt（可选）」，并说明团队运行由指挥者每次 `@` 时下发角色指令；模板库隐藏。
   - 变量提示：`{{team.roster}}`、`{{workspace.path}}` 等。
   - 模板库入口（通用助手 / 前端 / 评审 / 反方）。
4. **能力**
   - Skill：多选列表，显示来源与版本；「管理 Skill」链接。
   - MCP：Server 列表 + 每个 Server 的工具允许/拒绝；「管理 MCP」链接。
   - 预览「最终注入清单」。
5. **行为**
   - 上下文压缩阈值：滑块 + 数字，步长 100k（100k / 200k 两档，默认 200k）。
   - 保留最近消息数（默认 20）。
   - 权限：工作区路径、危险操作审批策略（每次询问 / 总是允许 / 禁止）。
   - 最大运行时长（默认 30 分钟）。
6. **右侧预览**
   - 页签：`最终 Prompt` / `测试对话`。
   - 最终 Prompt 以只读等宽展示，变量已替换为示例值。
   - 测试对话：发送一条测试消息，显示运行时与耗时，不写入正式会话。

**底部操作条**：取消 / 保存。保存后回到列表，显示 toast「已保存」。

### P06 团队列表

- 顶部：`智能体团队` + `新建团队`。
- 卡片网格（2–3 列）：团队头像、名称、描述、指挥者、成员头像堆叠、最近使用、快照数；卡片右上角提供删除。
- 模板区：`从模板创建`（头脑风暴队 / 前后端开发队 / 评审队）。
- 空态：说明团队与单智能体的差异 + 创建按钮。

### P07 团队编辑

## 6. 组件规格

### 6.1 智能体头像

- 圆形，32 / 40 / 56 三档；头像内容为确定性几何纹理或上传图。
- 右下角状态点：在线绿、运行中品牌色脉冲、离线灰、错误红。
- 团队头像：2×2 成员头像拼贴；不足 4 人用品牌底色补位；超过 4 人取前 4，不显示 `+N`。

### 6.2 Mention chip

- 结构：16px 头像 + 名称；背景为角色色 8% 透明；文字为角色色加深。
- 指挥者 chip 额外显示小皇冠/星标。
- 悬停显示成员卡片；点击跳转到该成员最近消息。
- 不可用时（离线/被移除）：虚线边框 + 删除线 + tooltip 原因。

### 6.3 消息

- 用户：右对齐，`--surface` 背景 + 1px 边框，圆角 14px，最大宽 78%。
- 智能体：左对齐，无气泡；左侧 2px 角色色竖线；头部 13px；正文 14/22；最大宽 100%。
- 系统事件：居中，12px，`--muted`，上下细线或不带线。
- 流式：末尾 2px 宽光标，品牌色；停止后光标消失。
- 失败：底部红色提示条 + 「重试」；错误详情可展开。

### 6.4 运行状态条

团队会话右侧「本回合」：

- 每行：头像、名称、状态文案、耗时、进度点。
- 状态：排队（灰）、启动中（黄脉冲）、工作中（品牌色脉冲）、等待审批（黄）、已完成（绿勾）、失败（红）。
- 顶部汇总：`3 工作中 · 1 排队 · 1 等待你`。

### 6.5 回合分隔

- 居中细线 + 文本：`第 2 轮 · 交叉辩论`；右侧可展开「本轮调度」查看 @ 关系图（P1）。
- 颜色弱化，不与消息争视觉。

### 6.6 输入框

- 容器：`--surface`，1px 边框，圆角 14px，聚焦时边框品牌色 + 2px 外发光。
- 多行自适应 1–8 行；超过后内部滚动。
- 底部工具条：左侧 **`+` 按钮**、`@` 提及、`/` 能力引用、当前工作区（文件夹图标 + 名称）；右侧字数/发送。
- 点击工作区打开系统文件夹选择器；选中后按目录名切换已有工作区或创建新工作区。
- **`+` 菜单**（点击后向上弹出）：
  - 添加文件 / 添加图片
  - 引用 Skill（已挂载且启用）
  - 引用 MCP 工具（只读展示工具名）
  - 打开工作区文件夹
  - 引用会话 / 产出物（P1）
- **`/` 选择器**：输入 `/` 打开，列出已挂载的 Skill 与内置命令（如 `/stop`、`/clear`）；选中插入 `/skill-name` chip。支持搜索、↑↓、Enter、Esc。
- 待发送区：输入框上方以 chip 展示本次附件与引用，可单独移除。
- 运行中：发送按钮变为停止（方形图标）；显示「排队」/「插话」切换。
- 路由提示：输入框上方 12px 文本，随 @ 目标变化。

### 6.7 连接测试步骤

- 步骤行：序号圆点、名称、状态图标、耗时。
- 进行中：圆点脉冲 + 细进度条。
- 失败：红色 + 展开错误详情。
- 全部成功：顶部绿色横幅「连接成功」+ 能力摘要。

## 9. 响应式与可访问性

- ≥ 1280px：三栏全开。
- 1100–1279px：右侧栏默认关闭，可手动打开覆盖在主区上。

- 遵循 `prefers-reduced-motion`：关闭脉冲与滑动，仅保留淡入。

## 10. 原型说明

原型位于 `prototype/`，使用原生 HTML/CSS/JS，无需构建：

```bash
cd prototype
python3 -m http.server 4173
# 打开 http://localhost:4173
```

原型覆盖页面：P01–P13 的主路径、P14 右侧栏、P15 提及选择器、P16 审批、P17 空态。P1 功能以禁用标签或「即将支持」标注，不假装可用。

**原型不做的事**：不连接真实运行时、不持久化、不实现真实 ACP、不执行文件操作。所有数据为演示数据，交互用于评审信息架构与视觉方向。
