# Pizza UI 原型

高保真、可点击的 Pizza 界面原型。使用原生 HTML / CSS / JavaScript，无构建步骤、无外部依赖。

## 运行

```bash
cd prototype
python3 -m http.server 4173
```

打开 <http://localhost:4173>。

应用图标与品牌素材位于 `assets/`，说明见 `assets/README.md`。

> 也可以用任意静态文件服务器；直接双击 `index.html` 也能查看，但使用本地服务器可以获得更稳定的 hash 路由体验。

## 可以体验的交互

- **多工作区**：左侧栏并列展示工作区，会话直接挂在所属工作区下；置顶工作区进入顶部「置顶」分组；没有工作区的会话归入默认工作区；行内 `+` 在该工作区新建对话，`⋯` 支持置顶 / 取消置顶 / 编辑 / 归档工作区。
- **会话菜单**：右键会话或点击悬停出现的 `⋯`，可重命名、分叉会话、导出会话、归档、永久删除；分叉会复制当前会话并切换到新会话，头部显示「分叉」标记。
- **工作区首页**：显示名称、目录、活跃会话数与置顶按钮。
- **参与者下拉**：首页点击「参与者」，在「智能体 / 智能体团队」分组中选择；选中即切换单智能体/团队模式，当前项带勾选。
- **命令面板**：点击头部搜索或 `⌘K`，搜索会话、智能体、团队与命令；`↑↓` 选择，`↵` 执行，`Esc` 关闭。
- **`@` 提及**：在输入框输入 `@`，弹出成员选择器；选择后插入提及。
- **`/` 引用 Skill**：输入 `/` 打开 Skill 与命令列表；选择后插入 `/skill-name` 并生成待发送 chip。
- **`+` 菜单**：添加文件、图片、引用 Skill/MCP、工作区与产出物；生成可移除的待发送 chip。
- **发送与流式回复**：发送消息后模拟智能体逐字回复；运行中可点击停止。
- **工具调用**：点击工具行展开参数与结果。
- **ACP 连接测试**：在「运行时 → 添加运行时」点击「测试连接」，逐步完成握手、临时会话、测试消息与清理，成功后启用「注册运行时」。
- **团队覆盖**：团队编辑 → 成员 → 「覆盖」打开抽屉，修改 Prompt / Skill / MCP。
- **快照**：团队编辑 → 快照 → 保存当前配置。
- **主题**：右上角月亮/太阳按钮，或设置 → 语言与外观。
- **右侧栏**：包含「产出物 / 轨迹 / 变更 / Git / 审计」。
  - 产出物使用文件树：筛选文件、展开文件夹、M/A/info 状态，点击文件预览。
  - 轨迹展示参与者状态、调度/辩论/插话/收敛事件，以及每位参与者的 token 统计与合计。
- **编辑器选择器**：会话头部点击图标/下拉，选择访达、Cursor、VS Code、Zed、IntelliJ IDEA、终端或 Warp。
- **账户与帮助**：点击左下角头像打开账户菜单（个人资料 / 主题 / 语言 / 快捷键 / 文档 / 更新日志 / Discord / 退出登录）；点击「帮助」打开帮助菜单（文档 / 更新日志 / Discord / 反馈）。
- **团队与成员**：设置 → 团队，包含智能体、智能体团队、Skills、MCP、运行时与统计。
- **团队复用**：团队编辑 → 快照可保存/恢复/复制；团队列表可使用内置模板；团队成员可新建团队私有成员。
- **标题栏**：左侧栏折叠按钮与搜索位于头部左侧、交通灯旁；折叠后侧栏收为 64px 图标栏。
- **设置布局**：打开设置后进入独立视图，左侧为品牌、设置导航与底部「返回聊天」/主题切换，右侧为内容。
- **切换工作区**：点击输入区或首页的工作区名称，打开系统文件夹选择器；选中目录后切换或创建对应工作区。
- **快捷键**：`⌘K` 命令面板、`⌘J` 单智能体对话、`⌘N` 新建对话、`⌘⇧B` 切换右侧栏、`Esc` 关闭浮层。

## 说明

- 所有数据均为演示数据；不连接真实运行时，不执行文件操作，不持久化。
- P1 功能以 `P1` 标签或「原型演示」提示标注，不假装可用。
- 原型用于确认信息架构、交互与视觉方向；确认后才进入代码阶段。
