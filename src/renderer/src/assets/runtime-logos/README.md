# Runtime brand logos

这些图标用于运行时列表、适配器选择器和首次启动检测结果，仅作产品识别用途。
商标与图形版权归各自厂商所有。

- `claude.svg`、`gemini.svg`、`pi.svg`、`omp.svg`、`opencode.svg`、`qoder.png`：
  来自 AionUI / AionCore 的 `aionui-assets`（Apache-2.0）。
- `hermes.svg`：Nous Research Hermes Agent 标记，经 LobeHub Icons 获取。
- `codex.png`：OpenAI Codex GitHub 头像，已转为透明单色蒙版以适配明暗主题。
- `dsh.svg`：DeepSeek Harness 桌面端的托盘图标。
- `kimi.svg`：Moonshot Kimi 品牌标记，来自 AionCore 的 `ai-china` 资源。
